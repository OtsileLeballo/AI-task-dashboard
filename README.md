 AI Task Dashboard

> A smart task management application with an AI-powered suggestion system that helps users prioritize and track their work effectively.

  Features

- **Add Tasks with** priority levels (High/Medium/Low)
- **Mark Tasks** as complete or incomplete
- **Delete Tasks** you no longer need
- **Filter Tasks** by status (All/Pending/Completed) and priority
- **Live Statistics**: Shows total tasks, completed, pending, and completion rate
- **AI Suggestion System**: Provides smart, contextual advice based on your task patterns
- **Progress Visualization**: A dynamic progress bar showing completion percentage
- **Data Persistence**: All tasks are saved in your browser's local storage
- **Responsive Design**: Works on mobile and desktop

##  Built With

- **HTML5** - Structure
- **CSS3** - Styling, animations, and responsive design
- **JavaScript (Vanilla)** - All logic and interactivity
- **LocalStorage API** - Data persistence

💡 How It Works
The AI Task Dashboard provides intelligent task management:

Add a Task: Type a task, select priority (High/Medium/Low), and click "Add Task"

Track Progress: The dashboard shows live statistics and a progress bar

AI Suggestions: Based on your task patterns, the system gives smart advice

Filter Tasks: View tasks by status or priority

Data Persistence: All tasks are saved automatically in your browser
